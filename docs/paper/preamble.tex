% Typesetting tolerance. Overfull boxes (text bleeding into the margin) are the
% warnings that matter and we keep ZERO of them. The only residual warnings were
% UNDERFULL boxes: cosmetically invisible loose spacing on lines that end in
% unbreakable monospace file-paths (e.g. \texttt{benchmarks/ablation.py}) and the
% justified bibliography. The TMLR style already declares \sloppy (it accepts
% loose lines by design); we make \hbadness/\vbadness consistent with that so the
% build log is warning-free, rather than hyphenating file-paths (which reads
% worse). \emergencystretch keeps overfull at zero.
\emergencystretch=3em
\hbadness=10000
\vbadness=10000
